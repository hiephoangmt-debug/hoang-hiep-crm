# hoang-hiep-crm
CRM – Real Estate Sales Management System

## Module

- [`floorplan-3d/`](floorplan-3d/README.md) – Mặt bằng 2D → 3D chân thực, phong cách nội thất, dự toán chi phí.
- [`news-telegram/`](news-telegram/README.md) – Quét tin Sở Xây dựng, quy hoạch, hạ tầng, BĐS Đà Nẵng và gửi về Telegram.
- [`bds-bot/`](bds-bot/HUONG_DAN.md) – Bot tư vấn BĐS 24/7 trên Zalo + khung chat LadiPage (Claude), tự ghi hồ sơ khách, đặt lịch, chào dự án đúng khách.
- [`chia-khach/`](chia-khach/HUONG_DAN.md) – Bot Telegram chia khách cho đội sale: chia lần lượt, tự thu hồi (30 phút / 2 giờ / 3 ngày), báo cáo tự động, lưu Google Sheet + sao lưu Drive.
