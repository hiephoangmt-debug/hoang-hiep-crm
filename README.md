# hoang-hiep-crm
CRM – Real Estate Sales Management System

## Trang tạo chỉ căn

Mở `chi-can.html` (file tĩnh, không cần build):

1. Nhập thông tin căn: mã căn, tòa, tầng, diện tích, view, giá, điểm nổi bật.
2. Chọn ảnh vị trí, mặt bằng tầng, layout 2D/3D. Có sẵn ảnh mẫu Four S Tower trong `assets/four-s/`.
3. Kéo chuột trên mặt bằng để khoanh ô đỏ quanh căn.
4. Bấm **Tải ảnh PNG** để gửi khách qua Zalo, hoặc **In / PDF**.

Dữ liệu đang nhập được lưu tự động trên trình duyệt.
