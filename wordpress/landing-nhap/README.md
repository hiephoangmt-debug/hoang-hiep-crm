# Bản nháp landing chưa bật trên web

Các file `fours-tower*.html` dựng từ landing sun-fours-tower.com (scripts/landing-fours.py). Chưa bật vì nội dung trùng nguyên văn
với sun-fours-tower.com – chờ anh Hiệp chọn: viết lại chữ cho hiephoangmt.com, hay đặt canonical về web landing.
Bật: chép các file vào wp-content/themes/hoanghiep/landing/ rồi đóng gói giao diện.
